# NM Pictorial Map Generator

The vintage "Land of Enchantment" county map on `explore.html` is a static inline
SVG generated by these scripts. To change it (move a label, add a landmark, adjust
colors), edit the data tables at the top of `gen_map.py`, then:

```
python gen_map.py         # regenerates nm_map_fragment.svg + nm_map_preview.html
python splice_explore.py  # re-splices the SVG into explore.html
```

Note: `splice_explore.py` matches the *original* tile-grid markup on first run;
after the first splice, replace the old `<div class="nm-map-wrap" ...>...</div>`
block manually or adapt the script's `old_map` string to match the current page.
(Simplest: `git checkout explore.html` is NOT an option once committed — instead
regenerate and swap the `<svg class="nm-map" ...>...</svg>` element.)

- `make_nm_svg.py` — one-time conversion of Census 2010 5m county GeoJSON
  (gz_2010_us_050_00_5m.json from eric.clst.org, public domain) into projected
  SVG paths + centroids (`nm_counties_svg.json`). Only needed if geometry changes.
- `gen_map.py` — the map itself: palette, county label offsets, rivers, Route 66,
  cities, landmark emoji, tribal-nation labels, banner, compass. All positions are
  lon/lat, projected with the same equirectangular transform as the county paths.
- County `<path>`s carry `class="county-shape" data-county="<slug>" data-name`;
  `initCountyExplorer()` in `assets/js/app.js` wires clicks/keyboard/aria at load.
  Slugs must keep matching `countySlug()` in app.js (`Doña Ana` → `dona-ana`).
